# AGENTS.md

## Objetivo del proyecto

Este proyecto es una landing page profesional para ofrecer servicios de desarrollo web.

## Stack actual

- HTML
- CSS
- WSL 2
- Ubuntu
- VS Code
- Git
- OpenCode

## Reglas de trabajo

Antes de modificar código:

1. Explicar qué archivo se va a tocar.
2. Explicar por qué ese archivo existe.
3. Explicar qué parte visual o estructural será afectada.
4. Mostrar el cambio de forma clara.
5. No borrar secciones sin explicar.
6. Mantener HTML semántico.
7. Mantener CSS organizado.
8. No agregar JavaScript todavía sin aprobación.

## Relación principal de archivos

index.html llama a:

- css/styles.css

css/styles.css controla:

- Colores
- Layout
- Botones
- Tarjetas
- Espaciado
- Responsive design

docs/plan.md sirve como documentación interna del proyecto.

README.md sirve como documentación pública del proyecto.

## Estilo de explicación esperado

Para cada cambio, explicar:

- Código principal.
- Archivo donde va.
- Qué hace.
- Qué archivo lo usa.
- Cómo probarlo.
- Resultado esperado.
