# Plan del proyecto: Landing Servicios Dev

## Objetivo

Crear una landing page profesional para presentar servicios de desarrollo web y captar posibles clientes.

## Público objetivo

Personas, negocios pequeños o emprendedores que necesitan:

- Una página web profesional.
- Automatizar procesos simples.
- Mejorar su presencia digital.
- Crear un formulario de contacto.
- Entender qué servicio contratar.

## Secciones principales

1. Header con navegación.
2. Hero principal.
3. Servicios.
4. Proceso de trabajo.
5. Sobre mí.
6. Llamado a la acción.
7. Footer.

## Stack inicial

- HTML
- CSS
- VS Code
- WSL
- Git
- OpenCode

## Reglas

- No usar JavaScript todavía.
- Mantener HTML semántico.
- Mantener CSS organizado.
- Usar nombres claros de clases.
- Crear una base profesional reutilizable.
